# 실제 시장 데이터 조건식 연구 서비스 범위

## 제품 한 문장

이 서비스는 **키움 API로 수집한 실제 시장 데이터 위에서 조건식을 작성·검증하고, 동일한 데이터셋과 가정으로 결과를 재현·비교하는 연구 워크스페이스**다.

> 주문 전송, 계좌 관리, 포지션 추적, 자동매매, 지정 단말 설정은 제품 기능이 아니다. 실제 데이터 수집에 필요한 인증은 서버 내부 연결 조건일 뿐 사용자 워크플로가 아니다.

## 사용 흐름

| 순서 | 사용자가 하는 일 | 시스템이 보장하는 것 |
| --- | --- | --- |
| 1. 데이터셋 | 유니버스·기간·가격 조정 기준을 고정 | 데이터 원본 버전과 수집 상태를 기록 |
| 2. 조건식 | 지표·연산자·논리 그룹을 조합하고 버전을 저장 | 조건식 스냅샷과 평가 근거를 보존 |
| 3. 검증 | 조건 충족 근거와 실제 일봉을 확인 | 예시 수치 없이 실제 데이터 또는 연결 대기만 표시 |
| 4. 실험 | 정보 절단·체결·비용·기간 분할을 고정해 실행 | 동일 입력으로 재현 가능한 백테스트를 기록 |
| 5. 비교 | 단일 실험과 워크포워드 결과를 비교 | 데이터셋 버전·종목·성과·낙폭을 함께 표시 |

## 화면 구조

연구 전용 화면은 네 개로 제한한다. **연구 개요**는 데이터셋·조건식·실험의 현재 상태와 다음 행동을 보여준다. **조건식 설계**는 규칙 편집·저장·충족 근거를 담당한다. **데이터 탐색**은 데이터셋별 실제 일봉·종목 분석만 제공한다. **검증 스튜디오**는 데이터셋 고정, 실험 명세, 백테스트, 워크포워드, 결과 비교를 하나의 연속된 흐름으로 제공한다.

## 제거·비노출 대상

| 대상 | 처리 원칙 |
| --- | --- |
| 주문 의도·주문 전송·체결·포지션·계좌 | 연구 화면·탐색·상태 배너에서 제거. 기존 안전 차단 코드는 유지하되 제품 흐름에 노출하지 않음 |
| 매수 한도·일일 횟수·킬 스위치 | 연구 제품에서 제거 |
| 지정 단말·IP·OAuth 상태 문구 | 사용자가 조작하거나 판단할 요소로 표시하지 않음. 실제 데이터 수집이 불가능할 때만 중립적인 `데이터 연결 대기` 상태로 축약 |
| 실시간 체결 감시·자동매매 후보 | 연구 제품에서 제거 |
| HTS 현재 후보 | 과거 백테스트와 분리된 보조 관찰 기능으로만 보류하며, 핵심 내비게이션에서는 제외 |

## 실제 데이터 연결 원칙

키움 OAuth·지정 단말 인증은 **새 데이터 수집을 위한 서버 내부 선행조건**이다. 인증이 통과하지 않아도 사용자는 기존에 고정된 데이터셋으로 조건식을 설계하고 실험 기록을 검토할 수 있다. 새 데이터가 필요할 때 연결이 실패하면 서비스는 주문·IP·보안 설정 화면 대신 `실제 데이터 연결 대기`와 재시도 가능 여부만 표시한다.

## 비목표

이 서비스는 투자 추천, 주문 실행, 자산 현황 관리, 수익 보장 도구가 아니다. 조건식은 실험 가능한 가설이며, 결과는 데이터셋·비용·체결 가정에 종속된 연구 기록으로만 취급한다.
