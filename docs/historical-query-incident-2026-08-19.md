# 과거 연구 실행 조회 오류 점검 기록

## 신고된 오류

2026-08-19 21:37 KST 개발 미리보기에서 `autonomous_research_runs`를 `runKey LIKE '%:historical%'` 조건으로 조회할 때 tRPC 오류가 보고됐다.

## 초기 대조 결과

- 실제 데이터베이스의 `autonomous_research_runs`에는 조회 SQL이 요구하는 14개 열이 모두 존재한다.
- 같은 조건의 SQL을 데이터베이스에서 직접 실행했으며, 로컬 실제 일봉 연구 실행 `#210001`을 정상 반환했다.
- 개발 미리보기를 다시 열어 조회 완료 상태까지 확인했을 때는 신고된 쿼리 오류가 재현되지 않았다.

따라서 스키마 불일치보다는 개발 서버 재시작·연결 일시 실패 또는 `Promise.all`의 병렬 조회 중 특정 요청 오류가 과거 연구 실행 조회로 표면화된 가능성을 우선 점검한다. 재발 시 개별 조회를 독립적으로 실패 처리하고 실제 데이터 화면의 핵심 조회를 차단하지 않도록 보완한다.

## 수정 후 확인

단일 과거 연구 조회 실패를 독립 처리하는 회귀 테스트를 추가하고 전체 테스트를 통과시킨 뒤, 개발 미리보기와 공개 도메인에 접속했다. 초기 로딩 시에는 기존처럼 `저장 연구 불러오는 중` 상태가 표시되며, 이 시점에 신고된 tRPC 오류 메시지는 재현되지 않았다. 이어서 공개 도메인의 조회 완료 상태에서 실제 일봉 불변 스냅샷 19종목·11,419개 봉, 과거 연구 실행, 생존 조건식과 운영 상태가 정상적으로 표시되는 것을 확인했다.
