# 공개 백테스트 경험 배포 확인

최신 체크포인트 `a2d8fff6` 저장 직후 공개 도메인 `kiwoomdash-nrgntfm8.manus.space`를 캐시 무효화 쿼리 문자열과 함께 두 차례 확인했다. 두 응답 모두 이전 화면 제목 `자동 조건식 리서치`와 이전의 작은 생존 후보 카드를 반환했으며, 새 제목 `조건식 연구 결과`, `저장 일봉으로 새 실험`, 생존 조건식의 상세 보기 구성은 아직 공개 자산에서 확인되지 않았다.

개발 미리보기에서는 새 화면이 정상 렌더링되고, 선택 후보의 전체 규칙·실제 진입/청산 타점·거래별 성과도 확인했다. 따라서 기능 코드·개발 미리보기는 준비됐지만, 이 기록 시점에는 공개 정적 자산 전환을 추가로 확인해야 한다.

이후 공개 도메인을 다시 확인해 새 자산 전환을 확인했다. 공개 화면에는 `조건식 연구 결과` 제목, `저장 일봉으로 새 실험` 버튼, 큰 데이터·성과 카드, 인샘플·독립 OOS·워크포워드 용어 설명, 생존 조건식의 `상세 보기` 진입 카드가 표시됐다. 현재 공개 인스턴스의 egress IP는 `152.55.180.34`로 표시됐으므로, 키움 OAuth의 지정 단말 등록값은 배포 인스턴스마다 달라질 수 있는 운영 환경 제약을 계속 주의해야 한다.
