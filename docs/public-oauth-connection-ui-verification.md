# 공개 OAuth 연결 확인 UI 검증

2026-08-15 개발 미리보기에서 공개 자동 리서치 대시보드를 확인했다. 데스크톱 1280×720과 모바일 375×812 화면 모두에서 서버 egress IP 안내 아래에 `키움 OAuth · 서버 연결 확인` 카드가 표시되며, `키움 연결 확인` 버튼과 현재 기기가 아닌 배포 서버가 OAuth를 확인한다는 안내 문구를 읽을 수 있었다.

확인 전 상태는 `키움 OAuth 연결 확인 필요`로 표시되며, 실제 토큰·App Key·App Secret은 어떤 화면 요소에도 표시하지 않는다. 모바일에서는 카드의 안내와 버튼이 한 열로 분리되어 터치 영역과 문구 가독성이 유지된다.
