# 게임형 조건식 연구 플랫폼 설계 기록

## 2026-08-20: 조건검색 연동 조사 메모

키움 공식 Open API+ 안내 검색 결과에는 영웅문 조건검색식의 **실시간 조건검색**, 실시간 등록·해지 기능이 명시되어 있다. 키움 REST API 안내 검색 결과에도 국내주식 조건검색 요청이 `ka10172`로 노출된다. 따라서 1차 구현은 영웅문에서 사용자가 이미 저장한 조건검색식의 식별자·이름·결과 종목을 가져와 전략 카드의 원천으로 기록하는 방향을 검토한다.

다만 외부 API가 영웅문 조건식의 내부 규칙 트리 전체를 역직렬화해 제공한다는 근거는 아직 확인되지 않았다. 따라서 서비스 자체의 표준 조건식은 독립적인 규칙 트리·파라미터·버전·데이터셋·실행 가정·검증 증거를 저장해야 하며, 영웅문 조건식은 `linked_hero_condition` 원천으로 연결하되 지원하지 못하는 구성 요소를 명시적으로 표시해야 한다.

## 현재 엔진과 게임 모델의 대응

| 현재 연구 모델 | 게임형 표현 | 보존해야 할 검증 기준 |
| --- | --- | --- |
| 고정·버전 관리된 실제 데이터셋 | 아레나 | 원천, 종목 유니버스, 기간, 조정 기준, 지문 |
| 조건식 프리셋·진화 후보 | 전략 카드 | 규칙 트리, 파라미터, 버전, 출처, 소유자 |
| 백테스트·독립 검증·워크포워드 | 대결 기록 | 비용, 슬리피지, 진입 시점, 미래 정보 차단 |
| 생존·제외 판정 | 카드 등급·검증 배지 | 표본 수, 기대값, 낙폭, 재현성, 제외 사유 |
| 주문 의도·확인·전송 | 실행 단계 | 연구·모의·승인·실전 분리, 위험 한도, 감사 로그 |

## 설계 원칙

카드의 등급이나 전적은 손익만으로 정하지 않는다. 같은 카드가 여러 버전 고정 아레나의 독립 검증과 워크포워드를 통과했는지, 표본과 낙폭 기준을 충족하는지를 함께 표기한다. 공유된 카드에는 작성자·복제 계보·원본 지문·공개 범위·검증 데이터셋을 고정해, 성과 주장과 실제 재현 결과를 구분한다.
