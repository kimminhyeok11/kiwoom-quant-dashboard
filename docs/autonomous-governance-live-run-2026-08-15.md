# 실제 데이터 자율 연구 거버넌스 실행 기록

## 실행 범위

2026-08-15에 저장된 키움 조정 일봉 **12,000개**, 20개 종목, 2024-02-27~2026-08-14의 고정 원본을 근거로 연구위원회 완료 보고서 `90001`을 사용했다. 예시·생성 시장 데이터, 주문·계좌 데이터, 미기록 장중 시퀀스는 입력에서 제외했다.

## 부장 AI–팀장 AI 결과

부장 AI와 담당 팀장 AI의 자율 개선 사이클 `1`은 `gpt-5-mini`로 완료됐다. 최종 상태는 `requires_more_validation`이며, **실전 승격 허용은 false**로 저장됐다. 세 개의 담당 팀장 후속 검토가 저장됐고, 조건식·청산 규칙을 주문 또는 실전 확정 규칙으로 승격하지 않았다.

| 구분 | 확인 결과 |

| 원본 | 저장된 키움 조정 일봉 12,000개·20종목만 사용 |
