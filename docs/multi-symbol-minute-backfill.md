# 다종목 연도 분봉 백필 운영 기록

## 유니버스 원칙

분봉 백필은 대표 종목 하나가 아니라, 저장된 실제 조정 일봉의 **최근 30거래일 평균 거래대금**으로 선발한 유동성 유니버스를 사용한다. 현재 기준선은 평균 거래대금 **100억 원 이상**이며, 유니버스·분봉 원본·장중 관찰·조건식 검증·자동 주문 계획이 같은 종목 집합을 참조한다.

키움 공식 REST 가이드는 연속 데이터가 있으면 응답의 `cont-yn` 및 `next-key`를 다음 요청 헤더에 전달하도록 명시한다. 백필 실행기는 `ka10080`을 같은 방식으로 페이지 단위로 호출하고, 연도 범위를 벗어난 행은 제거하며, 완결된 OHLCV 1분봉만 서버에 동기화한다. [1] [2]

## 2026년 실제 수집 검증

2026-08-19 KST에 사용자 컴퓨터의 지정 IP에서 올해 실제 `ka10080` 원본을 읽기 전용으로 수집했다. 평균 거래대금 100억 원 이상 기준의 19개 종목에 대해 19개 gzip 원본을 저장했고, 서버의 `intraday_minute_bars`에는 2026-01-02부터 2026-08-19까지 154거래일·1,100,571개 1분봉이 저장됐다. 이 수집은 주문·계좌 조회·주문 전송을 호출하지 않는다.

로컬 원본은 종목별 gzip JSON으로 보관하고, 각 종목의 완료·실패·행 수·페이지 수를 `progress.json`에 기록한다. 중단되면 완료된 종목을 건너뛰어 재개한다. 현재 수집된 19개 gzip 원본의 총 크기는 약 23.5MB이다.

## 운영 경계

| 항목 | 현재 동작 |
| --- | --- |
| 유니버스 | 최근 30거래일 평균 거래대금 100억 원 이상 실제 일봉 종목 |
| 과거 분봉 | 키움 `ka10080` 연속조회, 날짜별 검증·중복 제거·배치 upsert |
| 실시간 장중 | 당일 완결 1분봉·실제 시세를 같은 `intraday_minute_bars`에 동기화 |
| 연구·검증 | 실제 분봉 원본과 일별 실험 기록을 분리해 재현 가능한 조건식 평가에 사용 |
| 주문 | 별도의 활성 정책·로컬 계좌번호·킬 스위치·당일 신호가 모두 충족될 때만 가능 |
