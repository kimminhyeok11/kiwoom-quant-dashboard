# 공개 과거 백테스트 UI 검증

개발 미리보기에서 공개 자동 리서치 대시보드를 검증했다. 데스크톱 1280×720 화면에는 `HISTORICAL RESEARCH` 구역과 `과거 실제 일봉 백테스트` 제목, 실행 버튼이 OAuth 연결 카드 바로 아래에 표시됐다. 카드 문구는 키움 `ka10081` 실제 일봉을 고정 저장해 100개 조건식을 인샘플·독립 OOS·워크포워드로 평가하며 주문·계좌 조회를 호출하지 않는다는 점을 명시한다.

모바일 375×812 화면에서도 기존 연결 상태 카드와 백테스트 카드가 한 열에 자연스럽게 배치된다. OAuth 미확인 상태에서는 백테스트 버튼이 비활성화되어, 브라우저가 키움 연결을 확인한 뒤에만 실제 데이터 수집을 시작할 수 있다.
