# 공개 과거 백테스트 배포 확인

최신 체크포인트 저장 직후 공개 도메인 `kiwoomdash-nrgntfm8.manus.space`를 확인했으나, 화면에는 기존 OAuth 연결 카드까지만 보이고 `과거 실제 일봉 백테스트` 카드가 아직 표시되지 않았다. 개발 미리보기에는 카드가 정상 표시되고 전체 회귀·타입 검사를 통과했다.

따라서 이 시점의 공개 도메인은 최신 정적 자산 전환이 확인되지 않은 상태로 기록한다. 실제 일봉 백테스트 실행은 공개 도메인에서 새 카드·버튼이 표시된 뒤에만 검증한다.

이후 새 정적 자산 전환을 확인했고, 공개 도메인에는 `과거 실제 일봉 백테스트` 카드와 실행 버튼이 정상 표시됐다. 그러나 같은 공개 도메인에서 OAuth 확인을 다시 실행했을 때 서버 egress IP는 `34.202.227.85`로 표시되었고 `8050 지정단말기 인증 실패` 대기 상태가 반환됐다. 앞서 OAuth 성공을 표시했던 배포 인스턴스와 현재 요청 인스턴스의 실제 출발지 경로가 다를 수 있으므로, 고정 egress가 보장되지 않는 한 실제 일봉 백테스트 실행은 안전하게 비활성 상태로 유지된다.

이후 OAuth가 성공한 공개 인스턴스에서 실행된 과거 백테스트는 데이터베이스 기록상 2026-08-15 11:10:04에 시작해 11:10:05에 완료됐다. `ka10081` 조정 일봉 12,000개와 중복 없는 자동 조건식 100개, 생존 후보 12개가 저장됐고, 공개 화면에서 데이터 기간·일봉 수·조건식/생존 수·비용 가정 및 상위 후보의 인샘플·OOS·워크포워드 성과가 표시되는 것을 확인했다. 따라서 일시적인 “실제 일봉 분석 중” 표시는 결과 쿼리 재조회 시점의 화면 상태이며 백테스트 자체가 장시간 실행된 것은 아니다.
