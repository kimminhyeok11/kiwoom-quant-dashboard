# 공개 백테스트 경험 고도화 검증

2026-08-15 개발 미리보기에서 과거 실제 일봉 백테스트 결과를 확인했다. 첫 화면은 데이터 기간, 조정 일봉 원본 수, 조건식 선발 수, 정보 절단·비용 가정을 큰 성과 카드로 표시하며, 인샘플·독립 OOS·워크포워드의 의미를 바로 아래에서 설명한다.

생존 조건식 카드를 선택하면 선택 후보의 전체 논리 규칙 트리, 총 과거 수익률, 익절 거래 비율, 평균 수익·손실 거래, MDD, 거래 횟수가 표시된다. 대표 거래에는 실제 종가 흐름, 진입·청산 날짜와 가격, 진입 당시 충족한 규칙 근거가 함께 표시되고, 최대 40개의 실제 거래가 표로 제공된다.

`저장 일봉으로 새 실험`은 가장 최근의 고정 원본 일봉을 재사용하는 별도 실행 경로다. 이 경로는 키움 API를 다시 호출하지 않고 보존된 `autonomous_research_bars` 원본과 조건식 유전자를 이용해 새 후보 집합을 평가한다. 따라서 같은 데이터 기준일·조정 기준·유니버스에서 재현 가능한 비교를 유지한다.

모바일에서는 생존 조건식 성과 카드를 세로로 배치해 인샘플·독립 OOS·워크포워드 수치가 겹치지 않도록 했다. 데스크톱은 넓이 1440px에서도 생존 조건식 그리드를 최대 두 열로 제한해 각 성과 지표의 읽기 폭을 확보했다.
