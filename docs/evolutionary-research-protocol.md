# 진화형 조건식 탐색 연구 프로토콜

## 목적과 경계

이 기능은 실제로 고정된 일봉 데이터셋 위에서 조건식 후보를 반복 생성하고, **인샘플에서만** 선발·교차·변이한 다음, 생존 후보를 이전에 보지 못한 시간 구간의 워크포워드로 평가한다. 수익률이 높은 하나의 과거 구간만 남기는 자동매매 생성기가 아니라, 동일 데이터셋·비용·정보 절단 규칙으로 재현 가능한 가설 탐색 기록을 만드는 것이 목적이다.

## 세대 프로토콜

| 단계 | 기록·실행 규칙 | 과최적화 방지 장치 |
|---|---|---|
| 유전자 생성 | 허용된 조건 유형, 비교 연산, 기간, 임계값, 가중치, AND·OR·NOT 구조 안에서 시드 기반으로 생성한다. | 해석 불가능한 임의 코드·미래 데이터·지원하지 않는 지표를 유전자에 넣지 않는다. |
| 인샘플 평가 | 고정 데이터셋의 학습 구간에서만 비용·슬리피지·정보 절단 이후 체결 가정으로 성과를 계산한다. | 데이터셋 버전, 조건식 유전자, 시드, 비용 가정, 평가 기간을 함께 저장한다. |
| 선발 | 총수익률 하나가 아니라 최대 낙폭, 거래 수, 승률, 결측·무거래 패널티를 합친 적합도로 상위 후보를 고른다. | 최소 거래 수와 낙폭 한도를 만족하지 못하는 후보는 수익률이 높아도 탈락한다. |
| 교차·변이 | 상위 생존 후보 일부는 보존하고, 나머지는 부모 규칙·파라미터를 교차하거나 하나의 제한된 유전자만 변이해 다음 세대를 만든다. | 엘리트 보존 비율·교차율·변이율·최대 규칙 수를 실행 설정으로 고정한다. |
| 아웃오브샘플 | 인샘플에서 선발된 후보를 다음 독립 검증 구간에 적용하고, 여러 롤링 폴드의 결과를 합산한다. | 아웃오브샘플 수익률은 다음 세대의 선발 적합도에 직접 사용하지 않는다. |
| 보고 | 세대별 후보 수, 생존율, 인샘플 적합도, OOS 수익률·낙폭·거래 수, 실패 폴드를 모두 보존한다. | 성공 사례만 표시하지 않고 탈락·무거래·OOS 실패도 함께 보존한다. |

## 기본 실행 설정

초기 제품의 웹 요청 실행은 데이터셋이 준비된 상태에서 **소형 탐색 배치(예: 24~100 후보, 1~3 세대)**만 허용한다. 사용자가 말한 1,000개 규모의 반복 세대 탐색은 동일한 데이터 원본을 보존하되, 요청 제한·시간 초과·메모리 경계를 넘지 않는 별도 배치 실행 환경에서 수행한다. 이 대규모 실행의 자원 선택은 실제 데이터 수집 인증이 해결된 뒤 확정한다.

## 검증 기준

롤링 워크포워드는 과거 학습 구간에서 최적화한 조건식을 뒤의 미관측 검증 구간에 적용하고, 그 결과를 반복적으로 축적하는 방식이다. 이 방식은 단일 고정 구간의 최적화보다 과최적화·레짐 의존성을 드러내는 데 적합하지만, 창 길이 선택과 반복 최적화 자체가 편향·계산 부하를 만들 수 있으므로 실행 설정과 모든 폴드 결과를 기록해야 한다.[1] [2]

> 조건식 유전자는 사람이 읽을 수 있는 지표·기간·비교·논리 규칙으로만 구성한다. 최종적으로 살아남은 후보도 투자 추천이나 주문 신호가 아니라, 추가 검토가 필요한 재현 가능한 연구 가설이다.
