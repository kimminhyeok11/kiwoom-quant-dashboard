# HTS 조건검색 WebSocket 계약 및 연구 경계

키움 공식 조건검색 목록조회 문서에 따르면 `ka10171`은 영웅문4에서 만든 조건검색식을 목록으로 조회하는 WebSocket TR이다. 운영 환경은 `wss://api.kiwoom.com:10000/api/dostk/websocket`, 모의 환경은 `wss://mockapi.kiwoom.com:10000/api/dostk/websocket`이며 KRX만 지원한다. 요청은 JSON 본문 `{ "trnm": "CNSRLST" }`이고, 응답의 `data`에는 조건식 일련번호 `seq`와 이름 `name`이 포함된다. [키움 공식 조건검색 목록조회 ka10171](https://openapi.kiwoom.com/m/guide/apiguide?jobTpCode=15)

공식 가이드는 국내 조건검색에 일반 요청 `ka10172`, 실시간 요청 `ka10173`, 실시간 해제 `ka10174`도 별도로 열거한다. 이 프로젝트는 목록의 현재 후보를 시간 지정 관찰 스냅샷으로만 저장할 수 있으며, 해당 후보를 과거의 조건 충족 이력이나 백테스트 매수 신호로 역사용하지 않는다. 과거 연구에는 버전이 고정된 앱 조건식과 `research_daily_bars` 원본만 사용한다.

| 구분 | 허용 용도 | 금지 용도 |
| --- | --- | --- |
| HTS 현재 후보 | 관찰, 현재 시점 후보 기록, 워크포워드 보조 메모 | 과거 조건 충족 재구성, 과거 백테스트 신호 |
| 앱 조건식 + 고정 일봉 | 재현 가능한 단일 실험, 인·아웃오브샘플, 워크포워드 | HTS 현재 후보로 대체 |

실제 Node 서버 전송 형식·OAuth 토큰 전달은 지정 단말 인증이 정상인 환경에서 주문 없이 읽기 전용으로 검증한 뒤 확정한다. 인증 실패 또는 문서에 없는 전송 형식을 추정해 주문·계좌·과거 연구 경로로 확장하지 않는다.

2026-08-13 확인 시 목록조회 가이드는 추출 가능했으나, 브라우저에서 같은 조건검색 가이드 경로를 다시 열면 키움 포털 오류 `CD-14005`가 반환되었다. 따라서 일반 조건검색 `ka10172`의 세부 요청·응답 형식은 공식 세부 문서가 안정적으로 열리거나 지정 단말 인증이 성공한 뒤 읽기 전용 관찰로 재확인하기 전까지 운영 구현의 확정 근거로 사용하지 않는다.
