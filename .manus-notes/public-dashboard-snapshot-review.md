# 공개 대시보드 실제 원본 검수 기록

- 2026-08-18 KST 기준 개발 미리보기의 초기 화면은 상단 장중 자동 연구 실행 상태와 과거 일봉 연구 상태를 별도로 표시한다.
- 최신 실제 다종목 불변 스냅샷은 실행 120007, 19종목·11,400개 조정 일봉이며, 공개 과거 백테스트 완료 문구에 지정 IP ka10081 원본·종목 수·일봉 수·기간을 포함하도록 보완했다.
- 실제 원본 데이터가 없거나 tRPC 초기 조회가 아직 끝나지 않은 경우에는 기존의 명시적 대기 문구를 유지한다. 이는 예시 시장 데이터를 표시하지 않는 원칙과 일치한다.

개발 서버의 공개 `autonomousResearch.latest` 응답은 실행 120007을 `completed`·`ready` 및 `kiwoom_ka10081_local_snapshot`으로 반환했다. 대기 상태의 장중 자동 실행이 동시에 존재할 때에도 공개 상단은 이 완료된 실제 일봉 연구를 우선 선택하도록 변경했다. 스크린샷 캡처는 비동기 조회 완료 이전의 대기 문구를 찍을 수 있으므로, 이 항목은 공개 API 응답과 화면 계약 회귀 테스트로 함께 검증했다.
